# Инструкция агенту

## Назначение и границы

Локальный HTTP-сервис над Codex CLI: письма, оценка вакансий, анализ рынка и помощники.

## Карта кода

- `src/http.js`, `src/contract.js` — транспорт и контракты; `src/config.js` — окружение.
- `src/queue.js`, `src/analysis.js`, `src/resources.js` — очереди и допуск по ресурсам.
- `src/codex.js`, `src/auth.js`, `src/account-status.js` — CLI и авторизация.
- `src/telemetry.js` — безопасная диагностика; `test` — автономные тесты; `postman` — примеры API.

## Инварианты

- Не запускай несколько экземпляров на одном generation-data volume.
- Сохраняй идемпотентность по ключу и входу; не повторяй вызов модели после неопределённого результата.
- Анализы используют общий лимит и бюджет памяти; письма и помощники сохраняют свою последовательную очередь.
- Ожидающие ресурс задания остаются queued; не привязывай допуск к числу CPU.
- Auth status читает снимок; наличие auth.json не доказывает действующий вход.
- Не логируй credentials, email, prompts, ответы, thread IDs и сырой вывод CLI.
- Вход prompt считается данными; shell и web search остаются выключены.
- Различай RATE_LIMIT, AUTH_REQUIRED, сетевую ошибку, таймаут и ошибку контракта.

## Изменения и документация

Изменённый контракт одновременно отражай в клиентах, конфигурации, тестах и документации.
Проверяй утверждения по реализации. Не сохраняй планы, историю обсуждений и результаты
конкретных прогонов в постоянных инструкциях. Действующие причины решений описывай в архитектуре.
